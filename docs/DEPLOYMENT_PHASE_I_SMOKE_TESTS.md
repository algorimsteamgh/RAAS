## 4. Operational Ingress & Security Assessment

1. **Public Attack Surface:**
   - Only the frontend Container App is exposed externally via Cloud Envoy ingress at port 80/443.
   - The backend Container App is strictly configured with `ingress.external: false` and is accessible solely via the internal Envoy proxy within the Container Apps Managed Environment.
2. **Reverse Proxy Security:**
   - Nginx reverse-proxies `/api/*` requests internally with upstream read timeouts set to `300s` to accommodate LLM cold starts and heavy inference.
   - Static client assets are served directly from Nginx Alpine image with Gzip compression and zero direct database exposure.
3. **Database Concurrency:**
   - The backend Container App scale rule specifies `maxReplicas: 1` to guarantee single-writer serialized safety for SQLite database integrity.
